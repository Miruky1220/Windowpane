# Windowpane

A pixel desktop companion for keeping track of deadlines, journaling, and focused work.

一款像素桌面陪伴软件，用来记录 DDL 与日记，并陪伴专注学习和工作。

## Download / 下载

[Download Windowpane.exe](https://github.com/Miruky1220/Windowpane/releases/latest/download/Windowpane.exe)

Download the latest Windows x64 executable from **Releases** and double-click it to run.

前往 **Releases** 下载最新版 Windows x64 程序，双击即可运行。

This repository distributes the prebuilt executable only; the application source code is not included.

本仓库仅提供预编译的 exe 文件，不包含应用源代码。
